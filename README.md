# NLP_MachineTranslation

This project is a Python based Machine Translation Comparison Tool that translates sentences using DeepL and Google Cloud Translation. It compares the translation results, allows the user to rate adequacy and fluency, and saves the evaluation results to a JSON file for analysis.

The test cases were designed to evaluate different translation challenges, including simple sentences, idioms, ambiguous language, pronouns, word order differences, technical vocabulary, cultural expressions, gender bias, and formal language. These cases were used to compare how accurately and naturally DeepL and Google Cloud Translation handled a variety of translation scenarios.

Both DeepL and Google Cloud Translation produced accurate and fluent translations across the test cases. Most translations preserved the meaning of the original text while maintaining natural sentence structure in the target language. The most challenging test cases involved idioms, ambiguous wording, pronoun references, and culturally dependent expressions. While both translation services generally handled these cases well, they occasionally produced different word choices or phrasing to convey the same meaning. Overall, the translation systems showed strong performance in handling word order differences, technical terminology, formal language, and multi-clause sentences. Most variations between the services were stylistic rather than actual translation errors. The results suggest that modern machine translation systems are highly effective for general communication, although ambiguity, idioms, and gender-neutral language remain areas where translation quality can vary.

Both DeepL and Google Cloud Translation performed exceptionally well across the test cases. DeepL tended to produce slightly more natural and expressive phrasing in idiomatic and cultural expressions, while Google Cloud Translation often stayed closer to the reference translations. Both services handled simple sentences, technical vocabulary, formal language, and word order differences very effectively.
